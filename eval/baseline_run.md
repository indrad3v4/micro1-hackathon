# Baseline run — Creative Court eval (micro1, Measured Improvement)

**Дата:** 2026-08-28 · **Модель:** `deepseek-v4-flash-vision-exp` праз CometAPI (аднолькавая з advanced — параўноўваецца HARNESS, не мадэль) · **Ранэр:** `eval/run_eval.py baseline` · **Прагон:** 28.08.2026, 18:10–18:35 UTC (2 часткі, гл. «Чысціня прагону»)

## Азначэнне baseline
Чэсны мінімум, ухвалены Індра ў канцэпце: **адзін просты промпт** без агентаў, рубрык і суддзі:

> system: «Ты креатыўны кансультант. Прыдумай крэатыўную канцэпцыю для брыфа. Адкажы адным сувязным тэкстам: ідэя, чаму спрацуе, рызыкі.»
> user: поўны брыф (назва, апісанне, аўдыторыя, абмежаванні, мэта) + «Стварай крэатыўную канцэпцыю для гэтага брыфа.»

Вынік = **1 свабодны тэкст** на брыф. Без веера накірункаў, без скорынгу, без вердыкту, без трасіроўкі рашэнняў (акрамя запісу самага выкліку).

## Метадылогія метрык
- **Primary outcome:** адзін тэкст-канцэпцыя (без структуры → нельга ацаніць па рубрыках, параўнанне якасці гл. advanced_run.md §Якасць).
- **Human time per task:** час чалавека на падрыхтоўку і прыняцце рашэння. ASSUMPTION: усе 12 брыфаў ідэнтычна напісаныя загадзя, таму prompt-time = 0 у абодвух рэжымах; ацэнка рэвізіі адзінага тэксту супраць брыфа — ~3–5 хв, Advanced: веер з рубрыкамі скарачае да ~1–2 хв (суддзя ўжо адсек 1–3 з 6). Гэта адзіная непрамая метрыка — пазначана ASSUMPTION у канцы.
- **Cost per task:** аўтарытэтны `usage.cost` ад CometAPI; дзе API яго не аддаў (4/12) — токен-ацэнка па ставках самога CometAPI з рэальнага `cost_details`: in $0.1004/1M, out $0.66/1M. Сцяг `cost_estimated` у кожнай запісы `eval/results/merged_baseline.json`. Рэтраі (пусты content з-за reasoning) улічаны ў суме.

## Назіранні
1. **Адзін тэкст на брыф** — працавітая ідэя без альтэрнатыў: чалавек не бачыць веера і не можа параўноўваць frames (артстычны vs рытуальны падыход).
2. B12 (складаны канфліктны кейс): baseline знайшоў моцную ідэю «папяровы пашпарт» — сумленная адзнака; але **без суддзі** няма ацэнкі рызык трох бакоў (пастаўшчык ПО / арэндадаўца / агрэгатары) і няма edge-кейсаў.
3. Два доўгія выбухі (B06 191 с, B09 178 с) — reasoning-мадэль можа зацнуцца; advanced-стабільней (макс. 118 с).

## ASSUMPTIONs
1. **Human time** — не мяраўся стапамі; прынята, што напісанне брыфаў у абодвух рэжымах ідэнтычна (=0), а рэвізія выніку baseline ~3–5 хв vs advanced ~1–2 хв (веер + рубрыкі). Сапраўдныя лічбы патрабуюць хранаметражу жывой рэвізіі.
2. **Cost 4/12 кейсаў** — токен-ацэнка па ставках CometAPI (гл. вышэй), не фактычны invoice.
3. **Primary outcome** — колькасць/структура артефактаў (1 тэкст vs 6 накірункаў+вердыкты), не суб'ектыўная «якасць»; суб'ектыўнае параўнанне адкладзена да жывой рэвізіі чалавекам.
